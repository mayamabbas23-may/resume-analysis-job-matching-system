# Resume Analysis and Job Matching System

## Overview

This project is a SQL-based database system designed to manage resumes, analyze candidate skills, and match applicants with suitable job opportunities. The system stores user information, skills, job requirements, and company data to support efficient candidate evaluation and job matching.

## Technologies Used

* MySQL
* SQL
* MySQL Workbench

## Features

* Resume data management
* Skill mapping and analysis
* Job matching system
* Candidate evaluation
* Missing skill identification
* Relational database design

## Database Structure

The project consists of the following main entities:

* Users
* Skills
* UserSkills
* Companies
* Jobs
* JobSkills

These entities are connected through relational database concepts including primary keys, foreign keys, and many-to-many relationships.
